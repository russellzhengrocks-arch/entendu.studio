How to translate subtitles with a style guide and glossary

A subtitle translation needs more than words in another language. The project may specify line length, reading speed, approved names and terms, and other delivery rules. Start by giving the assistant the source file and the actual project requirements; then inspect the extracted rules and review the translation before delivery.

01

Prepare the source and requirements

Collect the original subtitle file, target language, current client style guide and approved glossary. Include additional reference material only when you have permission to use it. If instructions conflict or a requirement cannot be expressed, resolve it with the project owner rather than assuming a default is the client rule.

02

Provide clear terminology

A glossary is most useful when it identifies the source term, approved target form and any context needed to apply it. Distinguish approved translations from candidates and document exceptions. Names, aliases and relationships can depend on context; don't assume an identity from spelling alone.

In a fictional English-to-French test, SubA translated “We'll meet by the stage door.” as “On se retrouve à l'entrée des artistes.” using the supplied glossary. The exported SRT retained the three sample cues' identifiers, order and timing. This small example does not guarantee the same result for other files; review the translation and actual check results before delivery.

03

Review the rules and estimate

With SubA, provide the subtitle, style guide and glossary, then ask to see the effective rules and estimate before starting. Check language availability and your account balance. The SubA service and your chat host may use separate allowances.

04

Check the result and continue working

Review the actual translation and QC results, including unresolved terminology or formatting issues. Supported cue-level changes can be made on the existing job. If checks need attention, a labelled review draft can preserve the work; it should not be treated as a passed delivery. Export before the job expires and complete any required human and audiovisual review.
