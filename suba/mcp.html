SubA MCP server for subtitle localization

SubA provides a remote Model Context Protocol (MCP) service for subtitle translation, rule validation, checking, cue-level revision and original-format export. It is intended for subtitle files and professional localization workflows.

Connect to the service

Streamable HTTP · OAuth

The public SubA plugin uses Streamable HTTP and connects to:

https://mcp.entendu.studio/v1

The plugin uses an entendu. account and OAuth authorization through the host. A client must support the service's authentication flow. Host support and setup can vary: use the published SubA plugin or contact support@entendu.studio for current setup options. Do not paste access tokens or credentials into chat.

Capabilities

What the workflow supports

  • 1Load supported SRT, VTT, TTAL, TTML, PXTT and DFXP subtitle files, subject to format and structure limits.
  • 2Use project rules and glossaries, review an estimate and authorize translation before starting.
  • 3Inspect a completed job, review and revise individual cues, and export the result in the original format.
  • 4When checks report unresolved issues, preserve completed work as a clearly labelled review draft with the actual issues.

Check the returned status and issues; a review draft is not a passed delivery. A qualified person must review the result and any required audiovisual checks before final delivery.

Terms

Usage and data

SubA service usage is separate from your AI host's conversation or review allowance. Check language availability and the actual account estimate before adding funds or starting paid work. Jobs are normally available for seven days; export results before expiry. Account, glossary and billing records have separate retention. Only process content you are authorized to use.
