5 cues Getting started

Getting started with the SubA plugin

SubA helps subtitlers translate, check and revise subtitle files using project rules and glossaries. You need an entendu. account and a subtitle file.

View SubA plugin
  1. 100:00:01,000 → 00:00:04,000

    1. Connect SubA

    Open the SubA listing and select “Open in desktop app”. Follow the on-screen instructions to connect your entendu. account in a supported host. If you need help, contact support@entendu.studio.

  2. 200:00:04,000 → 00:00:07,000

    2. Prepare your project

    Have your subtitle file, source and target languages, and any applicable style guide or glossary ready. Only upload material you are authorized to process. SubA supports SRT, VTT, TTAL, TTML, PXTT and DFXP workflows, with limits for some complex file structures.

  3. 300:00:07,000 → 00:00:10,000

    3. Ask for an estimate

    In a chat with SubA connected, attach your materials and describe the work. For example:

    Review the extracted rules, current language availability, account balance and estimate before approving translation. SubA service usage and your AI host's conversation or review allowance are separate. Check availability for your target language before adding funds or starting.

  4. 400:00:10,000 → 00:00:13,000

    4. Review and revise

    Review the translation, actual QC status and outstanding issues. Request supported cue-level changes to the existing job when needed. If checks identify unresolved issues, a clearly labelled review draft can preserve the work for continued review; it is not a passed delivery.

  5. 500:00:13,000 → 00:00:16,000

    5. Export and complete human review

    Export the result and complete the required human and audiovisual review before delivery. Jobs are normally available for seven days, so export results before expiry. Glossary, account and billing records have separate retention periods.
